# Bancos-de-Dados
Trabalho do segundo semestre, banco de dados

# Perguntas de entrevista

Qual o problema?

Gerenciar os clientes e seus pagamentos.

Quais dados voces coletam do cliente
- Nome
- nascimento
- cpf
- sexo
- email
- telefone
- endereço(CEP)
- profissao.
- Numero de sessoes
- datas das sessoes
- horario da sessao
## Quais tipos de dados medicos dos pacientes que sao coletados? 


Quais sao os procedimentos possiveis?
- Sessão normal
- massagem tui ná
- Reflexologia podal
- Avaliação de palmilha ortopédica
- Na primeira sessao, é um valor diferente (registro diferente pra adicionar)

Tem plano de saude?

Não é particular apenas.

Quais as formas de pagamento possiveis?
- Dinheiro
- Debito
- credito
- credito parcelado
- PIX

Se tem avaliaçao fisica da pessoa?

Sim

OBS: As pessoas podem pagar mais de uma sessão ao mesmo tmepo por meio de pacotes, que da um desconto.
O pagamento é antecipado ou depois?
Na primeira é antecipado. depois pode pagar no dia que ela for.

Tem controle se a pessoa ja pagou?
Sim, tem um controle se ja pagou ou nao.
